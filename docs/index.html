Impostazioni del pulsante

Il pulsante avvia la rassegna su GitHub con un tuo token personale, che resta salvato solo in questo browser. Si crea una volta sola su github.com/settings/personal-access-tokens: in «Repository access» scegli Only select repositories e questo repository; in «Permissions» dai Actions: Read and write e nient'altro.

Senza token puoi avviarla anche dalla pagina del workflow su GitHub, con «Run workflow».
